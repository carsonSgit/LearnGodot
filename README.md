# Learn Godot 🎮✨

Game Programming & Development was one of the most fun parts of my Comp Sci DEC. I was thinking of something to do this summer and thought to myself, why not learn Godot to be able to make games easier? 🌞

I followed a great [YouTube tutorial](https://www.youtube.com/watch?v=LOhfqjmasi0) by [Brackeys](https://www.youtube.com/@Brackeys), and all of the materials I used are in the video description. 🎥📚

## What's the point? ❓🤔

My last game was made using `Tiled` and `JavaScript`, from that I ran into a lot of issues, mostly with `collision` and `world building`. I knew beforehand that game engines made these things a little simple, but I didn't realize how much easier. Godot really simplifies those complex aspects which helps a ton in development. 🕹️🚀

## My changes 🔧📝

My changes from the tutorial are minimal, but I more or less followed the tutorial as a loose guide as I already am more than comfortable in coding. 💻🔍
